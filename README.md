# Personal Utility Hub

Personal Utility Hub is a centralizing Windows-based desktop application designed to provide users with a suite of essential daily productivity tools. Accessed via a secure login gateway, it offers a unified interface for data transformation, note management, and profile organization.

### Key Features

*   **Multi-Format Data Conversion:** Robust utilities for string casing manipulation (Upper, Lower, Title Case), numerical base conversions (Binary, Hexadecimal, Octal), and custom XOR-based text encryption and decryption.
*   **Integrated Note Management:** A streamlined module for capturing information with native support for system clipboard integration and automated persistence to local text files.
*   **Automated Information Tracking:** A structured profile management system featuring dynamic age calculation and centralized storage of personal contact details.

### Technical Stack

*   **Language:** C#
*   **Framework:** .NET Framework 3.5
*   **UI Technology:** Windows Forms (WinForms)
